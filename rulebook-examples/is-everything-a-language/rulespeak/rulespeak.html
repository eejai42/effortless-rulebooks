ƒ Hockett Vs Gate Calculated 3 hops from ground truth string DR-13
In RuleSpeak®

The language candidate's hockett vs gate is determined by the following priority:

  1. an empty string if the hockett assessed count is 0
  2. “The eight-clause gate says language; Hockett's features hold for only ”, followed by the hockett yes count, followed by “ of ”, followed by the hockett assessed count, followed by a period if all of these hold:
    • the predicted answer flag is set
    • the hockett yes count is less than the hockett assessed count
  3. “Hockett's features all hold, and the eight-clause gate says not a language.” if all of these hold:
    • the predicted answer flag is not set
    • the hockett yes count is the hockett assessed count
  4. an empty string in all other cases
In plain words

= IF(Hockett Assessed Count = 0, "", IF(AND(Predicted Answer, Hockett Yes Count < Hockett Assessed Count), "The eight-clause gate says language; Hockett's features hold for only " & Hockett Yes Count & " of " & Hockett Assessed Count & ".", IF(AND(NOT(Predicted Answer), Hockett Yes Count = Hockett Assessed Count), "Hockett's features all hold, and the eight-clause gate says not a language.", "")))
