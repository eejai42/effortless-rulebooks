# ACME, LLC — Effortless Rulebook

**The smallest viable rulebook with a real calculated field — the "Hello, formulas" tutorial.**

A single business table (`Customers`) and two calculated fields that re-derive themselves
from raw inputs. No projects, no roles, no approval workflows — just a client ledger where
every customer carries two derived identifiers at once.

---

## What This Models

### The one table

- **Customers** — the client ledger. Raw fields: `EmailAddress`, `FirstName`, `LastName`.

### The two calculated fields

| Field | Kind | Formula | What it does |
|-------|------|---------|--------------|
| `Name` | formula | `SUBSTITUTE(EmailAddress, "@", "-")` | Slugifies the email into a stable handle |
| `FullName` | formula | `FirstName & " " & LastName` | The customer's full name |

Edit any raw field and every derived label rewrites itself in every substrate — Postgres
view, Python class, Go SDK, Excel cell, OWL ontology, CSV — with **zero application code**.

## Quick Start

```bash
./start.sh
```

`effortless build` is scoped to the folder it runs from:

| Run from | What rebuilds |
|----------|--------------|
| `acme-llc/` | All substrates (full rebuild) |
| `acme-llc/python/` | Python substrate only |

Proxy-backed transpilers (e.g. `python`) call `http://localhost:4242/...`; start the proxy
first if it isn't running (`./start.sh` handles this for you).
